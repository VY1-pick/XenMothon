# XenMotion 0.1.2 Beta — release review

Version: `0.1.2-beta` · Public beta · Windows x64

## Changes

- The default update source is this repository's public GitHub Releases API. Published betas with an uploaded Windows x64 installer are included; draft releases and unfinished assets are ignored.
- The highest release version is selected, rather than relying on creation order or GitHub's stable-only latest endpoint.
- Blank sources and the previous built-in raw manifest migrate to the new default. Custom HTTPS sources and an explicit update opt-out are preserved.
- The GitHub update source treats historical `0.9.0-beta.*` releases as preceding the new `0.1.2-beta` numbering. Generic semantic-version parsing and custom manifests retain numeric ordering.
- Settings explains the GitHub default. Updates remain notification-only; no silent download or installation is introduced.
- All 14 audit fixes from Beta 05 remain included; see [the earlier audit mapping](beta5-review.md).

## Upgrade from Beta 05

Install `XenMotion-0.1.2-beta-Setup-x64.exe` manually once. The already-published Beta 05 updater cannot recognize a numerically smaller version. The installer keeps the same application identity and current-user installation location; application library and settings are retained by the existing update/install flow. No automatic upgrade from the old binary is claimed.

## Validation

The .NET suite passes all 415 tests, and the quality lab passes all 41 behavioral checks.

The release pipeline builds the Release solution, runs the .NET suite, audits NuGet packages, publishes the application and native quality probe, includes the verified embedded Python archive and checks packaged file hashes before compiling the installer. The quality lab's behavioral checks and a redacted source/history secret scan are also run before publication.

## Limits

The installer is unsigned. Physical desktop display/audio behavior, real multi-monitor behavior and an installed Beta 05-to-0.1.2 upgrade/uninstall cycle were not re-tested for this release. The first 100 GitHub releases are checked. The new ordering is specific to the legacy XenMotion beta series; custom manifests still use normal numeric version comparison.

## فارسی

این نسخه با عنوان **0.1.2 Beta** و شمارهٔ `0.1.2-beta` منتشر می‌شود. پیش‌فرض آپدیت به ریلیزهای عمومی گیت‌هاب متصل است؛ بتاهای منتشرشده با نصاب کامل شناسایی می‌شوند و آدرس سفارشی یا خاموش‌بودن بررسی آپدیت حفظ می‌شود.

برای انتقال از بتا ۰۵، نصاب این نسخه را یک‌بار دستی اجرا کن؛ آپدیتر قدیمی شمارهٔ کوچک‌تر را نسخهٔ جدیدتر نمی‌داند. نسخهٔ جدید سری قبلی `0.9.0-beta.*` را قدیمی‌تر حساب می‌کند و دوباره آن را پیشنهاد نمی‌دهد.

نصاب امضای دیجیتال ناشر ندارد. آزمون واقعی تصویر/صدا، چندنمایشگر و نصب/ارتقا/حذف روی نسخهٔ قبلی در این انتشار تکرار نشده است.
