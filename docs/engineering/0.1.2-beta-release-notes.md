# XenMotion 0.1.2 Beta

**Public beta · 0.1.2-beta · Windows x64**

This release ships the GitHub-backed update source. It detects published betas and their complete Windows x64 installer, migrates the old default source and preserves custom sources and disabled update checks. Draft releases and unfinished uploads are ignored. Update checks only notify; they never install a release automatically.

**One-time manual upgrade from Beta 05:** the public version numbering has changed from `0.9.0-beta.*` to `0.1.2-beta`. The old updater uses numeric comparison and cannot offer this lower number. Download and run `XenMotion-0.1.2-beta-Setup-x64.exe` manually. New builds order the historical beta series before the new numbering and will not offer Beta 05 as a newer version.

The release includes the 14 fixes shipped in Beta 05. See [the release review](0.1.2-beta-review.md) for implementation scope and verification limits.

Download the installer and compare its SHA-256 with `SHA256SUMS.txt`. **The installer is unsigned.** Physical display/audio timing, multi-monitor behavior and a real installed upgrade/uninstall cycle were not re-tested.

## فارسی

**XenMotion 0.1.2 Beta** با منبع آپدیت مستقیم از گیت‌هاب منتشر می‌شود. بتاهای منتشرشده و نصاب کاملشان شناسایی می‌شوند؛ پیش‌فرض قدیمی منتقل می‌شود و تنظیم سفارشی کاربر حفظ می‌شود. آپدیتر فقط اطلاع می‌دهد و نصب خودکار انجام نمی‌دهد.

**از بتا ۰۵ یک‌بار دستی نصب کن:** شمارهٔ جدید `0.1.2-beta` از `0.9.0-beta.5` کوچک‌تر است و آپدیتر قبلی آن را پیشنهاد نمی‌دهد. نسخهٔ جدید ترتیب سری قدیمی را می‌شناسد و آن را آپدیت جدید حساب نمی‌کند.

نصاب امضای دیجیتال ناشر ندارد. فایل نصب و `SHA256SUMS.txt` همراه این ریلیز هستند. جزئیات در [گزارش نسخه](0.1.2-beta-review.md) آمده است.
